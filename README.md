## Run
```bash
npm install
npm run dev
```

Then open the Vite local URL.

## Build
```bash
npm run build
```

## Images
The `public/images` folder contains curated copies of the supplied WhatsApp photos. Crops, contrast, colour and sharpness were refined for web presentation; selected crops reduce distracting people/edge clutter without inventing project details. The site also includes one additional Indian-style interior reference from Unsplash and a few design elements from the supplied work.

## Replace photos
Drop new files into `public/images` and update the project list in `src/main.jsx`.
